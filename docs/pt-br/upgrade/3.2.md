# Guia de upgrade da versão 3.2

- A versão 3.2 muda principalmente a versão mínima do `PHP` para `8.2`.
- Atualiza os componentes `symfony/*` para suportar `^6.0 || ^7.0`.
- Atualiza o `phpunit/phpunit` para `^11.0`.

## Breaking Changes

1. O componente `async-queue` renomeou `JobInterface::getQueueName()` para `getPoolName()`.

```php
<?php
// Before
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getQueueName(): string
    {
        return 'custom';
    }
}

// After
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getPoolName(): string
    {
        return 'custom';
    }
}
```

2. A estrutura de configuração do `logger` foi alterada. Consulte [#7563](https://github.com/hyperf/hyperf/pull/7563).

3. A estrutura de configuração do `cache` foi alterada. Consulte [#7594](https://github.com/hyperf/hyperf/pull/7594).

4. Ao usar `swow`, adicione a dependência do response emitter.

```php
<?php
// config/autoload/dependencies.php

use Hyperf\Contract\ResponseEmitterInterface;
use Hyperf\Engine\ResponseEmitter;

return [
    ResponseEmitterInterface::class => ResponseEmitter::class,
];
```

## Upgrade de dependências

- Atualize a versão do php para `>=8.2`.
- Atualize o `elasticsearch/elasticsearch` para `^8.0 || ^9.0`.
- Atualize o `nikic/php-parser` para `5.6`.
- Atualize os componentes `symfony/*` para `^6.0 || ^7.0`.
- Atualize o `phpunit/phpunit` para `^11.0`.
- Atualize o `google/protobuf` para `^3.6.1 || ^4.2`.
- Atualize o `guzzlehttp/guzzle` para `^7.0`.

## Aviso

Se você atualizou para o PHP 8.4, `fgetcsv` e `fputcsv` agora exigem um valor padrão para o parâmetro `escape`.

```php
fputcsv($fp, $fields, escape: '');
fgetcsv($fp, escape: '');
```
