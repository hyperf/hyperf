## Quebras de Compatibilidade (BC breaks)

- O framework removeu o suporte a `@Annotation`, e usa o `Attribute` nativo do `PHP8`. Antes de atualizar, certifique-se de verificar se o projeto já foi convertido para usar `Attribute`.

O script abaixo pode ser executado para converter `Doctrine Annotations` em `PHP8 Attributes`.

**Nota: este script só pode ser executado na versão 2.2**

```shell
composer require hyperf/code-generator
php bin/hyperf.php code:generate -D app
```

- Script de atualização do Database Model

> Como a classe base do model adicionou suporte a tipos para as variáveis de membro, você precisa usar o script abaixo para atualizá-la para a nova versão.

```shell
composer require hyperf/code-generator
php vendor/bin/regenerate-models.php $PWD/app/Model
```

- O framework adicionou mais restrições de tipo à biblioteca de classes, então, ao atualizar de `2.2` para `3.0`, você precisa executar uma verificação estática para garantir que tudo funcione.

```shell
composer analysis
```

- O framework alterou o `Http status` retornado pelo `gRPC Server` de acordo com a especificação `gRPC`. Agora ele é fixado em 200, e o `gRPC Server` retorna o `status code` correspondente. Atualize o serviço para a versão 3.x.
