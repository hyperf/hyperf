# v3.2.0 - 2026-06-07

## Alterações Incompatíveis

1. BC do componente Carbon
    - `Carbon::createFromTimestamp()` não lê mais o timezone padrão via `date_default_timezone_get()` como fazia na `v3.0`.
    - `Carbon::diffInDays()` não retorna mais um valor absoluto por padrão. Use o parâmetro `$absolute` para controlar se o resultado deve ser absoluto.

2. [#7625](https://github.com/hyperf/hyperf/pull/7625) Renomeado `JobInterface::getQueueName()` para `getPoolName()` no componente async-queue, por consistência de terminologia.

```php
<?php
// Before
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getQueueName(): string
    {
        return 'custom';
    }
}

// After
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getPoolName(): string
    {
        return 'custom';
    }
}
```

```php
<?php

use Carbon\Carbon;

$t = time();

# The break usage
Carbon::createFromTimestamp($t, date_default_timezone_get());

# The correct usage
Carbon::createFromTimestamp($t, date_default_timezone_get());
```

3. A estrutura de configuração do `logger` foi alterada. Consulte [#7563](https://github.com/hyperf/hyperf/pull/7563).

```php
<?php

// Before
return [
    'default' => [
        'driver' => 'daily',
        'path' => BASE_PATH . '/runtime/logs/hyperf.log',
        'level' => env('LOG_LEVEL', 'debug'),
        'days' => 7,
    ],
];

// After
return [
    'default' => 'default',
    'channels' => [
        'default' => [
            'driver' => 'daily',
            'path' => BASE_PATH . '/runtime/logs/hyperf.log',
            'level' => env('LOG_LEVEL', 'debug'),
            'days' => 7,
        ],
        // Add your custom channels here
    ],
];
```

4. A estrutura de configuração do `cache` foi alterada. Consulte [#7594](https://github.com/hyperf/hyperf/pull/7594).

```php
<?php
// Before
return [
    'default' => [
        'driver' => RedisDriver::class,
        'packer' => PhpSerializerPacker::class,
        'prefix' => 'c:',
    ],
];

// After
return [
    'default' => env('CACHE_DRIVER', 'default'),
    'stores' => [
        'default' => [
            'driver' => RedisDriver::class,
            'packer' => PhpSerializerPacker::class,
            'prefix' => 'c:',
        ],
    ],
];
```

5. Adicionadas dependências ao usar `swow`.

`config/autoload/dependencies.php`

```php
<?php
use Hyperf\Contract\ResponseEmitterInterface;
use Hyperf\Engine\ResponseEmitter;

return [
    ResponseEmitterInterface::class => ResponseEmitter::class,
];
```

## Aviso

1. Se você atualizou para o PHP 8.4, note que tanto o método `fgetcsv` quanto o `fputcsv` agora exigem que seja informado um valor padrão para o parâmetro `escape`.

```
fputcsv($fp, $fields) must be changed to fputcsv($fp, $fields, escape: '')
fgetcsv($fp) must be changed to fgetcsv($fp, escape: '')
```
